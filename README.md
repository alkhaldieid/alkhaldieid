## What I Optimize For

- Evidence before automation.
- Human review as a designed control, not a vague fallback.
- Arabic fluency plus evidence, meaning, and decision-behavior evaluation.
- Replayable agent sessions: calls, arguments, state changes, permissions, and outputs.
- Systems that reduce institutional uncertainty rather than hiding it behind fluent interfaces.
